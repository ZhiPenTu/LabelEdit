# LabelEdit 界面设计

概念由内置 ImageGen 生成，路径：`editor-concept.png`。这是完整编辑器设计参考，真实界面使用原生 React 控件和实际 PDF 预览，不使用截图作为界面。

设计简报：完整桌面标签编辑器；白色顶栏、左侧文字列表、中央浅灰 PDF 画布、右侧文字编辑面板；清晰的打开/导出按钮；文字选择、拖框、识别框、缩放工具；原文字、替换内容、字体、字号、加粗、文字与背景颜色、自动适应、应用和修改记录。无渐变、装饰性统计、营销页面或嵌套卡片。

原生参考尺寸 1586×992。配色：白色界面，#f3f5f7 画布，#17212b 正文，#77828f 次要文字，#12806a 主色；控件 6 px 圆角，1.75 px 描边图标，13–15 px 界面字号。布局：顶部文件栏、工具栏、两侧白色面板、中央原比例白色标签纸，浅细边界。

概念文案：LabelEdit、打开 PDF、导出 PDF、选择文字、框选区域、显示识别框、文字区域、点击文字开始修改、搜索文字、重新识别、文件仅在本机处理、编辑文字、原文字、替换为、字体、加粗、字号、文字颜色、背景颜色、自动适应区域、应用修改、修改记录。

功能所需的有意差异：使用实际文件名和原 PDF 内容取代概念中的虚构示例标签；列表展示实际 OCR；增加语言选择、多页导航、撤销、删除记录、原稿对照、上传空态、加载与错误反馈。窄屏将侧栏改为可切换面板，保留完整画布和全部操作。
