# 电商工具中心 v0.2.1

- 修复安装后 Harness 内核启动即退出、无法打开工具的问题：显式打包内核启动所需的运行依赖。
- 打包验收改为将完整应用复制到源码目录外启动，避免开发目录中的依赖掩盖安装包缺失。
- 内核模块加载失败时展示具体错误原因，方便诊断。

v0.2.0 用户请下载本版本安装包，替换原应用；已安装插件和配置保留在用户数据目录中。更新仍通过 GitHub 手动安装，只展示最新版本变更日志。

支持 macOS 14+ Apple Silicon 和 Windows 10+ x64。安装包没有 Apple/Windows 发布者签名或 Apple 公证，系统可能显示安全提示。插件市场签名和系统沙箱保持启用。

macOS 14 / Windows 10 最低支持系统的手动验收和 remove.bg 真实 API 调用仍待完成。
