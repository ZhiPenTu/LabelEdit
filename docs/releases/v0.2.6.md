# 轻作 Qingzuo v0.2.6

修复插件卸载后重新安装出现工具服务不可用（`Error: 工具服务不可用。`）以及 macOS 应用更新清理抛出 `ENOTEMPTY` 的问题。

- **内核服务异步挂载修复**：在底座内核 `reconcile` 流程中完整等待 (`await`) 插件 Fiber 初始化与服务挂载完成，确保工具服务（如 `labeledit.pdf`）在协调返回时已就绪，解决卸载后重装因异步任务时序导致的“工具服务不可用”问题。
- **工具同步时序与视图协调**：在插件安装、卸载、启用、恢复与市场安装后，确保内核工具同步（`syncTools`）完成后再向渲染进程广播 `changed` 状态变更；在 `loadView` 阶段增加对同步中工具队列的等待协调，避免视图加载早于内核服务注册。
- **macOS 更新与临时目录清理容错**：在更新下载、差量/组件处理与解压清理流程中，增加 `withNoAsar` 与 `safeRm` 容错重试机制，规避 Electron 虚拟 asar 文件系统导致 `app.asar` 占用而触发 `ENOTEMPTY: directory not empty, rmdir .../Contents/Resources` 的问题；在组件更新降级到全量包时安全清理临时目录，确保更新流程稳定完成。
- **稳定性与自动化验证**：增加插件卸载后重新安装的服务注册与调用回归测试，以及 macOS 更新包 staging 清理与降级全量更新回归测试。

支持 macOS 14+ Apple Silicon、Windows 10+ x64。继续使用现有 GitHub 未签名分发模式。
