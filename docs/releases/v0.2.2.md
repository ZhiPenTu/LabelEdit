# 轻作 Qingzuo v0.2.2

电商工具中心现在叫「轻作」。新的应用名称、墨绿工具盒图标和统一界面，让标签编辑、插件发现和日常管理更清晰。

- 重新设计工具中心：暖白与墨绿配色、简洁侧栏、横向工具列表和更直接的市场入口。
- 重新设计插件市场：真实目录分类与搜索、安装/更新状态、可展开版本说明，以及加载失败重试和空结果反馈。
- 统一插件管理、外观设置、更新页面与 LabelEdit 编辑器的视觉设计，优化深色与窄屏布局。
- LabelEdit 插件升级为 v0.1.1，可通过签名市场独立更新至新界面；离线 OCR、PDF 文字编辑与原尺寸导出流程保持可用。
- 沿用原应用身份、用户数据目录和插件 ID，保留已安装插件与配置。安装包文件名继续使用 CommerceTools，以兼容旧版更新检查。

## 下载与安装

支持 macOS 14+ Apple Silicon、Windows 10+ x64。安装后的应用名为 **Qingzuo**，中文界面显示 **轻作**。当前继续通过 GitHub 分发未签名安装包，Mac 使用运行必需的 ad-hoc 签名；安装时可能出现系统安全提示。底座通过「更新」页面打开 GitHub 下载页，手动安装新版。

macOS 14 / Windows 10 的手动安装与升级验收仍待完成；remove.bg 真实 API 验收仍按现有决定暂缓。
