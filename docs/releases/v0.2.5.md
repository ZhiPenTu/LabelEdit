# 轻作 Qingzuo v0.2.5

优化 LabelEdit 插件工具栏界面布局，移除插件顶部冗余的主题切换按钮，统一由系统设置中的“外观”选项管理浅色、深色与跟随系统显示方式。

- 移除 LabelEdit 编辑器顶部操作栏中的主题切换按钮，避免与全局系统外观设置重复，精简界面并使文档操作更聚焦。
- 全局主题（浅色、深色、跟随系统）继续在轻作“设置”页的外观面板中统一配置，并实时作用于各插件视图与主工作台。
- 保持离线 OCR、原尺寸 PDF 编辑、导出与差量/组件更新能力。

支持 macOS 14+ Apple Silicon、Windows 10+ x64。继续使用现有 GitHub 未签名分发模式。
