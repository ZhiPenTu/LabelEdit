# 轻作 Qingzuo v0.2.4

新增差量下载、断点续传和 macOS 组件复用，减少后续更新重复下载的运行资源。更新仍在应用内完成：查看下载进度，下载并校验完成后自动安装和重启。

- macOS 优先读取生产密钥签名的组件清单，复用已安装且校验通过的 Electron、依赖、OCR 运行时和模型，只下载发生变化的组件。
- 组件不可用时尝试 ZIP 差量下载；缺少有效缓存或服务端不支持范围请求时回退到完整 ZIP，并显示原因。
- 下载失败可重试并续传，完整缓存复用前重新校验。所有路径都在完整性、应用身份、版本及代码签名检查通过后安装；安装交接失败时尝试恢复旧版。
- Windows 保留 Electron/NSIS 差量更新通道和自动安装重启。
- 完整离线安装包继续包含 OCR 运行时与模型；更新保留用户数据、已安装插件和配置。更新前请保存正在编辑的文件。

## 首次升级和下载大小

**v0.2.3 用户可在应用内升级到本版，首次仍需下载完整安装包。** 新的差量和组件能力从 v0.2.4 客户端开始生效。v0.2.0–v0.2.2 用户需手动安装本版一次。

后续下载大小取决于发生变化的组件及本地缓存；Electron、Python 依赖或模型升级可能仍需较大下载。组件按组下载，不保证每次更新只有几 MB。

支持 macOS 14+ Apple Silicon、Windows 10+ x64。macOS 请将应用放到有写入权限的“应用程序”文件夹后运行。继续使用现有 GitHub 未签名分发模式：Mac 使用运行所需的 ad-hoc 签名，Windows 安装包不带发布者证书；插件和组件清单的生产 Ed25519 签名校验保持启用。

macOS 14 / Windows 10 最低支持系统上的实际安装与升级验收仍待完成；remove.bg 真实 API 验收仍按现有决定暂缓。
