# 轻作 v0.2.7

轻作安装包只包含工作台和插件运行底座。LabelEdit 与 AI 抠图分别维护、发布和更新，从插件市场按需安装。

- 新安装首次打开可浏览市场或导入本地插件，无需安装开发运行时。
- 旧版内置 LabelEdit 改为独立插件，需要联网下载一次；配置、凭据和用户文件保留，主动卸载的插件不会恢复。
- 插件 API 1.1 支持通用私有文件资源、multipart 文件上传及文件响应，兼容已有 API 1.0 插件。
- 插件市场迁至独立仓库，发布制品经过验证、签名和上架 PR 审核。
- 底座不再打包 OCR 模型与业务 Python 后端；插件业务测试和构建由各自仓库负责。
- 修正 macOS 更新器对 ASAR 文件的读取。旧客户端安全回退到完整 ZIP 升级，v0.2.7 使用兼容旧格式读取的新组件签名域。

真实 remove.bg 计费调用及最低支持系统实机验收状态单独记录，CI 不替代这些验收。
