# 轻作 Qingzuo v0.2.3

更新现在可以在应用内完成：点击「下载并重启更新」，查看下载进度，下载完成后自动安装并重新打开轻作。

- 新增下载进度条、百分比和已下载大小，不再跳转 GitHub 下载页。
- macOS 下载 ZIP 并校验完整性，解压和验证应用后等待旧进程退出，再替换应用并重启；替换或启动交接失败时尝试恢复原版本。
- Windows 使用 Electron 更新器下载安装包，完成校验后静默安装并重新启动。
- 下载在后台持续进行，切换页面不会中断；网络、下载或校验失败时可重试。
- 保留原有用户数据、已安装插件和配置。开始更新前请保存正在编辑的文件。

## 首次升级

v0.2.0–v0.2.2 尚不包含应用内下载功能，首次升级到 **v0.2.3** 仍需安装本版安装包一次；此后的新版可以通过应用内更新。

支持 macOS 14+ Apple Silicon、Windows 10+ x64。macOS 请将应用放到有写入权限的“应用程序”文件夹后运行。继续使用现有 GitHub 未签名分发模式：Mac 使用运行所需的 ad-hoc 签名，Windows 安装包不带发布者证书；插件市场签名校验保持启用。

macOS 14 / Windows 10 最低支持系统上的实际安装与升级验收仍待完成；remove.bg 真实 API 验收仍按现有决定暂缓。
