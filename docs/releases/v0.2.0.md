# 电商工具中心 v0.2.0

- 新增统一工具中心、插件市场、插件管理、设置与更新入口。
- 通过 DeepSeek Harness 自定义 Profile 管理平台服务和插件生命周期。
- LabelEdit 成为默认附带的离线插件，支持 PDF 编辑、OCR、预览和导出。
- 新增独立 AI 抠图插件，使用用户配置的 remove.bg API 密钥。
- 支持导入、停用、卸载、独立更新插件，以及升级失败后的版本恢复。
- 网页插件和本地处理程序隔离运行，文件、网络与凭据通过宿主代理。

支持 macOS 13+ Apple Silicon 和 Windows 10+ x64。旧版用户请手动安装；旧版下载与更新清单已移除，版本标签和源码历史保留。
