# 电商工具中心 v0.2.0

- 新增统一工具中心、插件市场、插件管理、设置与更新入口。
- 通过 DeepSeek Harness 自定义 Profile 管理平台服务和插件生命周期。
- LabelEdit 成为默认附带的离线插件，支持 PDF 编辑、OCR、预览和导出。
- 新增独立 AI 抠图插件，使用用户配置的 remove.bg API 密钥。
- 支持导入、停用、卸载、独立更新插件，以及升级失败后的版本恢复。
- 网页插件和本地处理程序隔离运行，文件、网络与凭据通过宿主代理。
- 从 GitHub 分发桌面安装包；更新页只显示最新版本日志，打开对应 GitHub 下载页后手动安装。插件市场制品始终验证签名。

支持 macOS 14+ Apple Silicon 和 Windows 10+ x64。旧版用户请手动安装；旧版下载与更新清单已移除。

当前安装包没有 Apple/Windows 发布者签名或 Apple 公证，系统可能显示安全提示。macOS 运行资源使用 ad-hoc 签名；不涉及 App Store 上架。

双平台 CI 已通过真实沙箱、桌面界面和完整打包应用的离线 OCR / PDF 导出测试。macOS 14 / Windows 10 最低支持系统的手动安装与升级尚待用户验收；remove.bg 真实 API 调用和额度验收暂缓，使用前需要自行配置密钥。
