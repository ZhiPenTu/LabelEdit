# Bundled fonts

These static TrueType font files were instantiated at weights 400 and 700 from
Google Fonts' official variable fonts on 2026-10-07 using fontTools. Naming tables
were updated to describe the actual static weights.

- [Noto Sans SC source](https://github.com/google/fonts/tree/main/ofl/notosanssc)
  / [upstream font](https://github.com/google/fonts/blob/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf)
  / license: `NotoSansSC-OFL.txt`.
- [Arimo source](https://github.com/google/fonts/tree/main/ofl/arimo)
  / [upstream font](https://github.com/google/fonts/blob/main/ofl/arimo/Arimo%5Bwght%5D.ttf)
  / license: `Arimo-OFL.txt`.

Both are distributed under the SIL Open Font License 1.1. Keep the license files
with software distributions. Arimo is used as a substitute for the Arial option;
Microsoft Arial is not included in this software.
